# AI Use-Case Intake

One form for every new AI use case. It checks risk, process and value together, so nothing is approved on ambition alone.

## 1. The problem

- **Problem statement:** what is broken or slow today, for whom?
- **Current process:** steps, people involved, volume per month, time per item.
- **Redesigned process:** what changes *before* AI is added? Which steps go away?
- **Why AI:** could a rule, a workflow change, RPA or an existing tool solve this instead?
